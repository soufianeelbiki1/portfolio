# Engineering Portfolio

This repository is the public presentation layer for the `soufianeelbiki1` engineering portfolio.

It presents the same flagship systems through different hiring lenses rather than creating unrelated demo projects for every role.

## Portfolio map

- **AtlasPay** — payments, backend, distributed systems, reliability
- **AtlasRAG** — retrieval, evaluation, AI/LLM engineering
- **ForecastLab** — applied ML lifecycle and evaluation
- **Nexus** — platform/operator experience and distributed-systems operations

## Presentation rules

- Show implemented work, not roadmap items, as completed.
- Do not publish fake scale, traffic, latency, accuracy, or production claims.
- Do not publish a live-demo link until the deployment is verified.
- Explain architecture, failure modes, testing, trade-offs, and operational behavior.
- Keep project status synchronized with the underlying repositories.

The first site version is intentionally dependency-free so content, accessibility, and truthful engineering case studies can stabilize before choosing a heavier frontend stack.
