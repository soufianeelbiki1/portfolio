Seeded network scenarios

01 · Accepted authorizationISO 8583 request receives response code 00 and records a durable network observation.
02 · Timeout followed by late responseThe transport deadline expires with delivery uncertainty, then a later issuer response is correlated to the original STAN/RRN.
03 · Known-local transport failureA connection-refused-before-write path is recorded without pretending the request reached the issuer.

Run the actual integrated stack

Clone AtlasPay and Nexus as sibling directories, then run docker compose -f compose.demo.yml up --build from Nexus. Open Nexus on port 3000 and AtlasPay OpenAPI on port 8000.

AtlasPay is an engineering simulation. This walkthrough does not imply live card-network connectivity, real-money processing or production-scale traffic.
