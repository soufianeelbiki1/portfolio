Engineering

Systems and operational tooling

AtlasPay

Payments · Backend · PostgreSQL

Payment core

ISO 8583 and EMV boundaries, routing, STAN/RRN correlation, duplicate handling, timeouts, late responses and reversal correlation.

Durability

PostgreSQL idempotency, append-only double-entry accounting, transactional outbox delivery and read-only reconciliation.

Operations

Prometheus/OpenTelemetry instrumentation and a protected snapshot API consumed by Nexus.

Scope

AtlasPay is a simulation and does not connect to a live card network or process real money.

Nexus

Next.js · TypeScript · Operations UI

An operator console for AtlasPay with authenticated API access, runtime contract validation, transaction filtering and reconciliation views.

When live mode is configured, API or validation failures are shown as unavailable data instead of falling back to fixture values.

Source →

AtlasRAG

FastAPI · PostgreSQL · Retrieval

RAG backend with deterministic ingestion, durable document/chunk storage, citation-aware responses, weak-evidence abstention, rank fusion, reranking hooks and regression evaluation.

Semantic/vector retrieval is still planned; the current repository does not report vector-search quality.

Source →

ForecastLab

Python · FastAPI · ML evaluation

Passport-photo compliance rules with estimator interfaces, per-rule evidence, synthetic regression datasets and held-out evaluation tooling.

The current API evaluates signals; raw-image inference and measured real-world accuracy are not implemented yet.
